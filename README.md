# Superkauf

Einkäufe gemeinsam organisieren — Stammartikel-Katalog (Müsli, Tomaten, Butter, Waschmittel, …) plus eine aktive Einkaufsliste, aus der beim Einkauf einfach ausgewählt wird, was diesmal gebraucht wird. Mobile-first, gedacht für die Nutzung direkt im Supermarkt.

Setup: siehe [SETUP.md](SETUP.md).
